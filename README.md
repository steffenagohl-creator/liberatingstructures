# LS-Matchmaker

Eine App, die Moderatorinnen (z. B. Scrum Mastern) zu einer geschilderten Gruppensituation einen
passenden, begründeten **String aus Liberating Structures** vorschlägt – gedacht als Mischung aus
**Handbuch** und **Praxis-Werkzeug**.
